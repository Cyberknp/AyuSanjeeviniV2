# AyuSanjeeviniV2 Documentation

## Overview

AyuSanjeeviniV2 is a Flutter-based mobile application that provides AI-powered medical image analysis for skin and dental conditions, combined with real-time health vitals monitoring.

## Purpose

This documentation serves as the definitive technical reference for:
- New contributors joining the project
- Maintainers responsible for ongoing development
- DevOps engineers handling deployment and infrastructure
- Security reviewers conducting assessments
- Academic evaluators studying the system

## Quick Start

1. **Prerequisites**: Flutter 3.10+, Dart SDK, device with camera access
2. **Installation**: `flutter pub get`
3. **Run**: `flutter run`
4. **Build**: `flutter build <platform>`

## Key Components

- **Health Monitoring**: Real-time vitals tracking via Google Sheets integration
- **ML Analysis**: On-device TensorFlow Lite inference for medical images
- **Cross-Platform**: Android, iOS, Web, and Desktop support
