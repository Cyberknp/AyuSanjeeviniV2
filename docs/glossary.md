# Glossary

## Technical Terms

### Flutter & Dart
- **Flutter**: Google's open-source UI software development kit for creating cross-platform applications
- **Dart**: Programming language optimized for building user interfaces with Flutter
- **Widget**: Basic building block of Flutter UI, describing configuration for an element
- **StatefulWidget**: Widget that has mutable state and can rebuild when state changes
- **setState()**: Method in Flutter to trigger widget rebuild when state changes
- **Material Design 3**: Google's design system providing guidelines for visual, motion, and interaction design

### Machine Learning
- **TensorFlow Lite**: Lightweight version of TensorFlow for on-device ML inference
- **Inference**: Process of making predictions using trained ML models
- **Model**: Trained machine learning algorithm that can make predictions
- **Tensor**: Multi-dimensional array used in ML computations
- **Classification**: Task of predicting a discrete class label for input
- **Confidence Score**: Probability value indicating model's certainty in prediction
- **Argmax**: Operation that finds the index of maximum value in array

### Mobile Development
- **APK**: Android Package Kit, file format for distributing Android applications
- **IPA**: iOS App Store Package, file format for iOS applications
- **SDK**: Software Development Kit, collection of tools for developing applications
- **Asset**: Resource file bundled with application (images, models, etc.)
- **Hot Reload**: Flutter feature allowing instant code changes without app restart

## Medical & Healthcare Terms

### Medical Imaging
- **Dental Analysis**: Examination of teeth and oral cavity images for abnormalities
- **Skin Analysis**: Examination of skin images for conditions or diseases
- **Medical Image Analysis**: Process of extracting meaningful information from medical images
- **Diagnosis**: Identification of disease or condition based on symptoms and medical data

### Vital Signs
- **Heart Rate**: Number of heartbeats per minute (BPM)
- **Blood Pressure**: [Unverified – requires repository inspection] Force of circulating blood
- **Temperature**: Body temperature, typically measured in Celsius or Fahrenheit
- **Oxygen Saturation**: [Unverified – requires repository inspection] Percentage of oxygen-saturated hemoglobin
- **Steps**: Count of steps taken, typically measured by accelerometer

### Health Monitoring
- **Real-time Monitoring**: Continuous tracking of health metrics
- **Threshold**: Predefined value that triggers alert when exceeded
- **Calorie Estimation**: Calculation of calories burned based on activity
- **Health Dashboard**: Interface displaying multiple health metrics

## Data & Networking Terms

### Data Formats
- **CSV**: Comma-Separated Values, file format for tabular data
- **JSON**: JavaScript Object Notation, lightweight data interchange format
- **Uint8List**: List of 8-bit unsigned integers in Dart
- **Byte Array**: Sequence of bytes representing binary data

### Networking
- **HTTP**: Hypertext Transfer Protocol for data communication
- **HTTPS**: Secure version of HTTP with encryption
- **API**: Application Programming Interface for software communication
- **Endpoint**: Specific URL where API is accessed
- **Request**: Message sent from client to server
- **Response**: Message sent from server back to client
- **Status Code**: Three-digit code indicating HTTP request result

### Google Sheets Integration
- **Google Sheets**: Web-based spreadsheet application
- **CSV Export**: Process of exporting spreadsheet data as CSV format
- **Public Spreadsheet**: Sheet accessible without authentication
- **Cell Reference**: Specific cell location in spreadsheet (e.g., A1, B2)

## Application Architecture Terms

### Design Patterns
- **Monolith**: Single-unit application architecture
- **Service Layer**: Architecture layer containing business logic
- **Repository Pattern**: Design pattern for data access abstraction
- **Dependency Injection**: Pattern providing dependencies to components
- **Factory Pattern**: Creational pattern for object creation
- **Observer Pattern**: Behavioral pattern for event notification

### State Management
- **State**: Data that can change over time and affects UI
- **State Management**: Process of handling state changes in application
- **Provider**: Flutter package for state management
- **BLoC**: Business Logic Component pattern for state management
- **Riverpod**: Modern state management solution for Flutter

### Performance & Optimization
- **Lazy Loading**: Deferring initialization until needed
- **Caching**: Storing frequently accessed data for faster retrieval
- **Memory Management**: Process of allocating and deallocating memory
- **Battery Optimization**: Techniques to reduce battery consumption
- **Threading**: Running multiple operations concurrently

## Security Terms

### Authentication & Authorization
- **Authentication**: Process of verifying user identity
- **Authorization**: Process of granting permissions to authenticated users
- **API Key**: Unique identifier for API access
- **Token**: Piece of data used to authenticate requests
- **Session**: Period of interaction between user and application

### Data Protection
- **Encryption**: Process of encoding data to prevent unauthorized access
- **Hashing**: One-way function for data integrity verification
- **SSL/TLS**: Protocols for secure network communication
- **Certificate Pinning**: Security technique preventing MITM attacks
- **Data Anonymization**: Process of removing personal identifiers from data

### Compliance
- **HIPAA**: Health Insurance Portability and Accountability Act
- **GDPR**: General Data Protection Regulation
- **CCPA**: California Consumer Privacy Act
- **FDA**: Food and Drug Administration
- **CE Marking**: Conformité Européenne marking for European market

## Development & Operations Terms

### Version Control
- **Git**: Distributed version control system
- **Repository**: Storage location for code and version history
- **Branch**: Parallel version of code for development
- **Commit**: Save point in version control history
- **Merge**: Combining changes from different branches

### Testing
- **Unit Test**: Test of individual component or function
- **Integration Test**: Test of interaction between components
- **Widget Test**: Flutter-specific test for UI components
- **End-to-End Test**: Test of complete user workflow
- **Test Coverage**: Percentage of code tested by automated tests

### DevOps
- **CI/CD**: Continuous Integration/Continuous Deployment
- **Build Process**: Compiling source code into executable
- **Deployment**: Process of releasing application to users
- **Monitoring**: Tracking application performance and health
- **Logging**: Recording events and errors for debugging

## User Interface Terms

### UI Components
- **Splash Screen**: Initial screen shown when application launches
- **Navigation**: Process of moving between different screens
- **Modal Dialog**: Popup window requiring user interaction
- **Alert**: Notification to user about important information
- **Theme**: Consistent visual design across application

### User Experience
- **User Journey**: Path user takes through application
- **Onboarding**: Process of introducing new users to application
- **Accessibility**: Design considerations for users with disabilities
- **Responsive Design**: UI that adapts to different screen sizes
- **Dark Mode**: UI theme with dark background and light text

## Platform-Specific Terms

### Android
- **Gradle**: Build automation tool for Android projects
- **Manifest**: Configuration file for Android applications
- **Permissions**: User-granted permissions for device access
- **Activities**: Components representing single screens in Android

### iOS
- **Xcode**: Development environment for iOS applications
- **Info.plist**: Configuration file for iOS applications
- **CocoaPods**: Dependency manager for iOS projects
- **View Controller**: iOS component for managing screen content

### Web
- **DOM**: Document Object Model for web page structure
- **Responsive Design**: Web design adapting to different devices
- **Progressive Web App**: Web application with native-like capabilities
- **Browser Compatibility**: Ensuring application works across browsers
